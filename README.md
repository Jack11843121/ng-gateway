# NG 网关（NG Gateway）

> 网关大师系列 · Web/API 网关 —— 基于 Nginx（OpenResty），植入「管理端」能力的网关产品。

Nginx 是高性能、稳定、可靠的数据转发引擎，但管理能力弱。NG 网关在保留 Nginx 全部性能优势的同时，补齐 **配置、监控、运维、风控、安全** 五大管理能力，做成开箱即用、可一键部署的企业级网关。

- 📐 设计文档：[DESIGN.md](DESIGN.md)（当前处于「设计评审」阶段）

## 规划能力

| 能力 | 说明 |
| --- | --- |
| 配置管理 | 可视化路由/上游/证书/插件，动态热更新不 reload，版本化+灰度+回滚 |
| 监控 | QPS/延迟/错误率实时指标，Prometheus + Grafana，JSON 日志，链路追踪 |
| 运维 | 主动/被动健康检查、动态上游、平滑热更、集群纳管、审计 |
| 风控 | 多级限流、IP 黑白名单、WAF、反爬/CC 防护、地理封锁 |
| 安全 | HTTPS 多证书/自动续期、API Key/JWT/OIDC/mTLS、RBAC、密钥托管 |
